# AZA Digital Ecosystem

Одностраничный сайт (лендинг) цифровой экосистемы **AZA** — финтех, e-commerce, облака, образование и госуслуги в одной платформе.

## Технологии

- HTML5 (семантическая разметка)
- CSS3 (переменные, flexbox/grid, анимации, адаптив под мобильные)
- Vanilla JavaScript (без зависимостей и сборщиков)
- Шрифт Inter (Google Fonts)

## Структура проекта

```
aza-digital-ecosystem/
├── index.html          # Главная (и единственная) страница
├── css/
│   └── style.css       # Все стили
├── js/
│   └── main.js         # Меню, анимации, счётчики, форма, модальные окна проектов
├── assets/
│   └── favicon.svg     # Иконка сайта
├── README.md
├── .gitignore
└── LICENSE             # MIT
```

## Запуск локально

Просто откройте `index.html` в браузере — сборка не требуется.
Для корректной работы шрифтов нужен доступ к интернету.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите файлы.
2. В репозитории: **Settings → Pages → Source** → выберите ветку `main`, папку `/ (root)`.
3. Сайт будет доступен по адресу `https://<ваш-логин>.github.io/<название-репозитория>/`

## Для презентаций

Раздел «Проекты» создан для показа на презентациях: каждая карточка открывает
модальное окно с описанием, технологиями и результатами проекта.
Данные проектов редактируются в файле `js/main.js` (объект `projectsData`).
Скриншоты проектов можно добавить как `background-image` в классы
`.project__visual--1...6` в файле `css/style.css`.
Для показа на полный экран используйте F11 (полноэкранный режим браузера).

## Что заменить перед запуском

- Контакты в разделе «Контакты» (email, телефон, адрес) — файлы `index.html`.
- Ссылки на соцсети в подвале.
- Подключение реальной отправки формы (сейчас обработчик демонстрационный) — файл `js/main.js`, блок `form.addEventListener`.
- Названия и описания продуктов экосистемы — соответствуют реальности.
