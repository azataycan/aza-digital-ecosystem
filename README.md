Основатель — **Азамат Акматов**. Связь: WhatsApp **+996 507 66 88 66**.

Тема оформления — «Ночь над Тянь-Шанем»: звёздное небо с созвездиями,
цифровые горы и рассвет, открытие сайта «створками» с анимированным логотипом.

## Технологии

- HTML5, CSS3, Vanilla JavaScript — без сборки и зависимостей
- Шрифты Unbounded и Onest (Google Fonts, поддерживают кириллицу)
- Анимации: CSS, SVG и Canvas (небо и горы); при «уменьшении движения» в системе — спокойный режим

## Как изменить

**Номер WhatsApp.** В `js/main.js` — константа `WA_NUMBER`. В `index.html` найдите
`996507668866` и `+996 507 66 88 66` (ссылки, текст и QR-код). QR-код ведёт на
`https://wa.me/996507668866` — при смене номера его нужно сгенерировать заново.

**Проекты.** В `index.html` каждый проект — блок `<article class="project">`.
Название, подпись, метка («Скоро», «Для гостей» …) и описание редактируются прямо там.
Окно «Подробнее» берёт эти тексты из карточки автоматически и подставляет в
WhatsApp сообщение «Меня интересует проект …».

**Демо-экраны.** Сценарий каждого экрана задаётся атрибутами:
`data-steps` — число шагов, `data-ms` — длительность шагов,
`data-on="1 2"` / `data-from="3"` — когда элемент виден,
`data-vals` — числа по шагам. Тексты внутри экранов — обычный HTML.

**Фото основателя.** Положите `assets/founder.jpg` и замените блок
`<div class="portrait">…</div>` на
`<img class="portrait portrait--photo" src="assets/founder.jpg" alt="Азамат Акматов">`.

**Превью ссылки в WhatsApp/Telegram.** В `<head>` замените
`assets/og-image.png` на полный адрес, например
`https://ВАШ-ЛОГИН.github.io/aza-digital-ecosystem/assets/og-image.png`.

## Запуск

Откройте `index.html` в браузере — сборка не нужна (для шрифтов нужен интернет).

## Публикация на GitHub Pages

1. Загрузите файлы в репозиторий.
2. **Settings → Pages → Source** → ветка `main`, папка `/ (root)`.
3. Сайт будет по адресу `https://<логин>.github.io/<репозиторий>/`.

Для показа на презентации: F11 — полноэкранный режим браузера.
